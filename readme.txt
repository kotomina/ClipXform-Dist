【ソフトの概要】
ClipXformは、クリップボードの内容（テキスト、画像、ファイルパス）に対して
様々な変換処理を効率的に実行するためのWindows 11用常駐型ユーティリティです。

主な機能:
- テキスト変換: フォーマット変換(Camel/Snake等)、エンコード/デコード、カラーコード変換など
- 画像処理: AIを利用した画像からのテキスト抽出(OCR)、画像ファイルとしての保存
- ファイルパス処理: パスの形式変換
- AI連携: Local LLM (Ollama) および クラウドAI (Gemini, OpenAI, Anthropic) 対応による要約・校正・翻訳・画像生成
- スマートスニペット: 動的なプレースホルダーを活用した定型文貼り付け
- その他: クリップボード履歴、コマンドパレット、コンパクトモード搭載

【インストール方法】
1. 配布ファイル(ZIP等)を解凍してください。
2. 含まれているセットアッププログラム「ClipXformSetup_vX.X.X_Bundled.exe」をダブルクリックして実行します。
3. インストーラーの指示に従ってインストールを完了させてください。

※本ソフトの実行には .NET 9.0 Desktop Runtime が必要です。
　起動しない場合は、Microsoft公式サイトよりランタイムをインストールしてください。

【アンインストール方法】
Windowsの「設定」→「アプリ」→「インストールされているアプリ」から
「ClipXform」を選択し、「アンインストール」を実行してください。
